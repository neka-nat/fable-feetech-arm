# 6-Axis Robot Arm (Feetech STS3215 × 6)

`STS3215_03a.step`(Feetech STS3215 サーボ)を6個使った6軸ロボットアームのCADモデルです。
ブラケットの取り付けインターフェースはすべて STEP モデルから実測した寸法に合わせてあります。

## 生成方法

```bash
uv run python robot_arm.py                            # 直立姿勢で出力
uv run python robot_arm.py --pose "0,-40,70,30,50,0"  # J1..J6 [deg] を指定
```

出力:
- `robot_arm.step` — 指定ポーズの全体アセンブリ(サーボ6 + ブラケット7、部品ラベル・色付き)
- `out/parts/*.step` — ブラケット単品(3Dプリント用、ポーズ非依存)
- 実行時にペアワイズ干渉チェックを行い、重なりがあれば報告します(`--no-check` でスキップ)

## 3Dビューアでジョイントを動かす

ブラウザ上のスライダーで6軸をリアルタイムに動かせます(VS Code不要):

```bash
uv run python arm_viewer_viser.py
```

http://127.0.0.1:8080 をブラウザで開くと、右上のJ1〜J6スライダーで関節を
動かせます。メッシュは起動時に一度だけテッセレートし(初回は ~1分)、以後は
関節フレームの回転のみ更新するので操作はリアルタイムに反映されます。
`reset pose` ボタンで全関節を0(直立姿勢)に戻せます。

干渉チェックは行わないので、当たりが疑わしいポーズは `robot_arm.py --pose` で
確認してください(ペアワイズ干渉チェック付き)。

Pythonからは `from robot_arm import build_arm` で任意ポーズの
アセンブリ(`Compound`)を取得できます。

## 軸構成(ゼロ姿勢 = 直立)

| 軸 | 種別 | 軸方向 | 駆動部品 | 可動範囲(干渉チェック実測) |
|----|------|--------|----------|------|
| J1 | ベースヨー | Z | `base` → `b1_shoulder_mount` | ±180°(配線次第) |
| J2 | ショルダーピッチ | Y | `b1` → `b2_upper_arm`(リンク長 110 mm) | ±95° |
| J3 | エルボーピッチ | Y | `b2` → `b3_forearm` | −25°〜+95° |
| J4 | リストロール | Z | `b3` → `b4_wrist_mount` | ±180°(配線次第) |
| J5 | リストピッチ | Y | `b4` → `b5_wrist_link` | ±95° |
| J6 | ツールロール | Z | `b5` → `b6_tool_flange` | ±180°(配線次第) |

全高(直立時)約 371 mm、ショルダーからフランジまでの実効リーチ約 277 mm。
ピッチ軸の ±95° はコネクタプラグの掃引域回避、J3 の −25° は折返し方向で
J4サーボがアッパーアームのウェブに当たる限界です。制御側でリミットを設定してください。

## サーボとの取り合い(STEPから実測)

- **ドライブホイール**: Ø20、面 z=+18.7、Ø2.5 の4穴(9.9 mm 角配置)→ **M3 ねじ**(穴はM3タップ下径)。
  中心ねじ頭(z=+20.2 まで突出)用に Ø9.5 の逃がし座繰りを各ブラケットに設けています。
- **アイドラホイール**: Ø20、面 z=−17.7、同一穴パターン。中心ボス Ø6(z=−18.3)用の Ø7 逃がし付き。
  U字ブラケットはホイール/アイドラ両面を掴む両持ち支持です。
- **上面タブ**: 面 z=+15.9、Ø1.5 下穴 ×4(−29.0/−8.3, ±10.25)→ **M2 タッピングねじ**(皿、面一)。
- **下面タブ**: 面 z=−15.9、Ø1.5 下穴 ×4(−32.8/−8.3, ±10.25、上面と非対称)。
  アッパーアーム(b2)先端はコネクタ窓と共存させるため後方の2本のみ使用します。
- **コネクタ**: 底面後部のベイに 3ピンヘッダ ×2(ピンØ2、真下向き、先端 z=−19.4)。
  プラグは真下から挿抜し、プラグ本体はサーボ底面から z≈−26.5 まで張り出します。
  各ブラケットはこの空間と、関節回転で掃引する円環域を逃がしてあります。
- **干渉回避**: ケース上面リブ(z=+17.0 まで)・コネクタベイにはクランプ板・パッドに逃がし窓/溝をカット。

## プリント公差(v2 で追加)

実機フィードバック(嵌合がきつい)を受けて、以下の嵌合クリアランスを入れています。

- ホイール/アイドラを掴むボス当たり面: **片側 0.35 mm**(M3 を締めると密着)
- タブクランプ面(クランプ板・パッド・ベースデッキ): **片側 0.2 mm**
- ホイール/アイドラ貫通穴: Ø23.6 / Ø24.0(斜め入れ込み組立を考慮)

## ハーネス取り回し(v2 で追加)

- **ベース**: 底板にサーボ挿入兼用の大開口があり、サーボ1は**下から**挿入します。
  プラグも下から挿し、ケーブルは底面の溝(深さ4 mm、後縁 −X 側へ)を通して外に出します。
  背面壁のスロットは手アクセス・予備の引き出し口です。J1→J2 のケーブルはベース外側を
  立ち上げ、J1 回転のたるみ(サービスループ)を確保してください。
- **アッパーアーム(b2)**: 肘側サーボ(J3)のコネクタはアイドラ側プレートの**貫通窓**から
  外側に挿抜します。ケーブルはアーム外側底面を這わせ、途中のタイラップ穴(Ø3.5×2組)で
  固定して肩側へ送ります。
- **肩・手首クランプ(b1/b4)**: クランプ板Bの窓からプラグが横に抜けます。
- **デッキ上のサーボ(J4・J6)**: コネクタ挿抜スペースがデッキ裏側で狭いため、
  **ケーブルを挿してからデッキに固定**してください。

## 組立・運用ノート

- ホイール用 M3 はスラブ/フランジに設けた Ø6 のドライバーアクセス穴から締めます。
  デッキ上のサーボ(J4・J6)はタブねじを締めてから次のブラケットを取り付けてください。
- U字ブラケットへのサーボ入れ込みは、ホイール側を先に穴へ掛けてから斜めに倒し込みます。
  b2 先端(J3)はリブ溝・ベイ溝に沿わせてスライドさせると入ります。
- 可動範囲は軸構成の表を参照(J3 の折返し側 −25° に注意)。
- ブラケット推奨: PETG/PLA、壁4周・インフィル40%以上。プレート厚は基本4 mm、
  タブクランプ板はホイール面との段差制約(2.8 mm)から 2.5 mm。
